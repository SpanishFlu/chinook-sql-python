# chinook-sql-python
Learning Python and SQL by analyzing the Chinook music store database.

# Querying with SQL & Python

## Goal
Analyze the Chinook digital music store database using Python,
SQLite, Pandas, and Matplotlib in a Jupyter Notebook.

## Business questions
- Which are the 10 best-selling tracks?
- Which country generates the most revenue?
- Who is the top-performing sales employee?

## Learning roadmap
- [ ] Phase 1: Variables, typecasting, and repository setup
- [ ] Phase 2: Python fundamentals and functions
- [ ] Phase 3: Jupyter setup and SQLite connection
- [ ] Phase 4: Explore tables and relationships
- [ ] Phase 5: Write SQL queries for business questions
- [ ] Phase 6: Load results into Pandas and create a bar chart
- [ ] Phase 7: Document findings and submit the project
